# Week 15 Submission Contents

- `reports/`: Activity 1, Activity 2, IA6, and reflection in editable Markdown plus verified DOCX/PDF soft copies.
- `diagrams/`: editable Mermaid, structural JSON, and SVG test-architecture view.
- `tests/`: exported Postman collection, live/full verification scripts, controlled fixtures, actual JSON/JUnit results, traceability matrix, defect/failure/regression records, and hardening backlog.
- `logs/`: sanitized test, build, audit, scan, initial-failure, environment, and document-QA records.
- `screenshots/app/`: four actual running Flutter Web captures.
- `screenshots/source/`: two actual VS Code source captures.
- `source/MANIFEST.md`: source-package preparation/provenance status.
- `EVIDENCE_INDEX.md`: evidence IDs, scenarios, times, hashes, results, build state, and limitations.
- `SUBMISSION_CHECKLIST.md`: module, activities, IA6, rubric, reflection, and Project 29 reconciliation.

Excluded intentionally: `.env`, fixture password, bearer tokens, keyring/private keys, private certificate keys, live database data, dependencies/build caches, `.git`, temporary document renders, and any claim of instructor acceptance. No final ZIP is created until the user confirms the Week 15 source commit/tag.
